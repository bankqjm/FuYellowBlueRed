## 一、项目概述

### 1.1 项目背景
FuYellowBlueRed 是一个开源外卖配送平台，支持消费者、商家、骑手、管理员四种角色。已完成 MVP 核心业务闭环（注册登录→浏览商家→加购→下单→支付→配送→评价），H5 移动端适配，账务系统，安全加固。

### 1.2 现有系统技术栈
- **前端**: React 18 + TypeScript + Ant Design 5 + Vite + Zustand + ESLint
- **后端**: FastAPI + SQLAlchemy (async) + SQLite + JWT + ruff
- **API**: 61个端点，18个数据模型，9个Schema文件

### 5.3 代码规范要点

**前端 (遵循阿里巴巴规范)**:
- 禁止使用 `var`，使用 `const` / `let`
- 使用单引号
- 尾部逗号 (multiline)
- 箭头函数使用括号包裹参数
- `if` 语句必须使用大括号
- 使用 `===` 而非 `==`
- 使用 camelCase 命名变量/函数
- 对象属性周围使用空格
- 行长度限制 120 字符

**后端 (遵循 PEP 8)**:
- 类名使用 CamelCase
- 函数/变量使用 snake_case
- 模块级常量使用 UPPER_CASE
- 行长度限制 120 字符
- 导入顺序: 标准库 > 第三方库 > 本地模块
