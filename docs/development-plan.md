## 二、分步开发计划

### Sprint 0：P0 核心功能完善（预计 5 天）

**目标**：完成所有 P0 核心功能的开发，确保产品基本可用

#### Day 1-2：支付倒计时系统

**前端任务**：
- 创建 `CountdownTimer` 通用倒计时组件
  - 文件：`frontend/src/components/CountdownTimer/index.tsx`
  - 功能：接收截止时间，显示倒计时，低于5分钟变红提示
- 在下单确认页面集成倒计时组件
  - 文件：`frontend/src/pages/user/Checkout.tsx`
  - 功能：显示15分钟支付倒计时

**后端任务**：
- 创建订单超时扫描定时任务
  - 文件：`backend/app/tasks/order_timeout.py`
  - 功能：每分钟扫描待支付订单，超时15分钟自动取消
- 添加定时任务调度器
  - 使用 APScheduler 或 FastAPI BackgroundTasks

**验收标准**：
- [ ] 下单后显示15分钟倒计时
- [ ] 倒计时低于5分钟显示红色警示
- [ ] 超时订单自动变更为"已取消"状态
- [ ] 超时订单无资金变动

#### Day 3：评价图片上传

**前端任务**：
- 在评价页面集成图片上传组件
  - 文件：`frontend/src/pages/user/Review.tsx`
  - 功能：支持上传1-3张图片，显示缩略图
  - 使用已有的 `POST /upload` API

**后端任务**：
- 评价图片存储字段
  - 模型：`Review` 表添加 `images` JSON 字段

**验收标准**：
- [ ] 评价时可上传1-3张图片
- [ ] 图片格式校验生效
- [ ] 图片显示在评价列表中

#### Day 4：商家商品图片上传

**前端任务**：
- 在商品管理页面集成图片上传
  - 文件：`frontend/src/pages/shop/Products.tsx`
  - 功能：商品主图上传、替换、删除

**验收标准**：
- [ ] 添加商品时可上传图片
- [ ] 编辑商品时可更换图片
- [ ] 图片上传校验生效

#### Day 5：测试与修复

- 全面测试 P0 功能
- 修复发现的问题
- 更新 API 文档

### Sprint Security：安全加固（预计 3 天）

**目标**：修复高危安全漏洞，提升系统安全性

#### Day 1：身份认证安全

**任务**：
- 实现密码强度校验
  - 后端：`POST /auth/register` 添加密码强度正则验证
  - 前端：注册页添加密码强度提示
- 实现登录限流
  - 使用 Redis 或内存存储失败次数
  - 5次失败锁定15分钟

**验收标准**：
- [ ] 密码需8位以上，含字母数字
- [ ] 登录失败5次锁定15分钟
- [ ] 锁定期间无法登录

#### Day 2：日志与审计

**任务**：
- 实现敏感日志脱敏
  - 文件：`backend/app/utils/logger.py`
  - 手机号中间4位脱敏为 `138****8888`
  - 金额保留2位小数，显示 `***.XX`
- 实现操作审计日志
  - 文件：`backend/app/models/models.py`
  - 模型：`AuditLog`（user_id, action, resource, details, ip, created_at）

**验收标准**：
- [ ] 日志中无完整敏感信息
- [ ] 关键操作有审计记录

#### Day 3：Token 安全升级

**任务**：
- 实现 HttpOnly Cookie 存储 Token
  - 后端：登录接口设置 Cookie
  - 前端：修改 auth.ts 读取 Cookie
- 添加安全响应头
  - 文件：`backend/app/main.py`
  - 头：CSP, X-Frame-Options, X-Content-Type-Options

**验收标准**：
- [ ] Token 存储在 HttpOnly Cookie
- [ ] 响应包含安全头

## 六、风险与依赖

### 6.1 技术风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 定时任务可靠性 | 超时订单可能未及时处理 | 使用稳定调度器，增加重试机制 |
| WebSocket 性能 | 高并发时连接数限制 | 考虑使用轮询替代 |
| 图片存储容量 | 大量图片占用空间 | 考虑对象存储 OSS/S3 |

### 6.2 业务风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 优惠券财务风险 | 优惠券滥用 | 设置使用条件和数量限制 |
| 安全漏洞 | 被攻击或数据泄露 | 定期安全扫描和渗透测试 |

### 6.3 依赖项

| 依赖 | 说明 |
|------|------|
| 后端 API 基础 | 已完成 |
| 前端组件库 | Ant Design 5 已配置 |
| 文件上传服务 | `POST /upload` 已实现 |
| 数据库模型 | 基础模型已完成 |
