## 五、问题发现与修复

### 5.1 问题一：路由顺序问题（FastAPI常见问题）

**问题描述**：FastAPI 按照路由定义的顺序进行匹配，当参数路由（如 `/{shop_id}`）定义在静态路由（如 `/categories`）之前时，静态路由会被错误地匹配到参数路由。

**影响范围**：商家分类列表接口 `/shop/categories` 无法正常访问。

**根本原因**：在 shop.py 中，`/{shop_id}` 路由在 `/categories` 之前定义，导致请求 `/shop/categories` 时被错误匹配到 `/{shop_id}` 路由，尝试将 "categories" 解析为整数而失败。

**修复方案**：调整路由定义顺序，将静态路由放在参数路由之前。新增 `/categories` 路由并放在 `/list` 和 `/{shop_id}` 之前。

### 5.2 问题二：SQLAlchemy 异步模式下的 Lazy Loading 问题

**问题描述**：在异步 SQLAlchemy 中使用 Pydantic 的 `model_validate()` 时，如果模型有 lazy loading 关系（如 `categories` 和 `products`），会导致 MissingGreenlet 错误。

**错误信息**：

```
MissingGreenlet: greenlet_spawn has not been called;
can't call await_only() here. Was IO attempted in an unexpected place?
```

**影响范围**：商家详情接口和商家分类列表接口返回 500 错误。

**根本原因**：Pydantic 尝试访问 SQLAlchemy 模型的关联属性时，触发了 lazy loading，而在异步上下文中 lazy loading 需要显式 await。

**修复方案**：不使用 `model_validate()` 直接验证 ORM 对象，而是手动构建 Pydantic 模型，显式查询关联数据后再赋值：

```python
# 修复前（会导致错误）
shop_data = ShopDetail.model_validate(shop)
shop_data.categories = [CategoryInfo.model_validate(cat) for cat in categories]

# 修复后（正确做法）
shop_data = ShopDetail(
    id=shop.id,
    user_id=shop.user_id,
    name=shop.name,
    ...
)
for cat in categories:
    products_result = await db.execute(select(Product)...)
    products = products_result.scalars().all()
    cat_data = CategoryInfo(id=cat.id, shop_id=cat.shop_id, ...)
    for product in products:
        cat_data.products.append(ProductInfo.model_validate(product))
    shop_data.categories.append(cat_data)
```

### 5.3 问题三：测试脚本路径不匹配

**问题描述**：测试脚本中的 API 路径与实际后端实现的路由不匹配，导致测试失败。

**影响范围**：测试用例中的部分路由返回 404 Not Found。

**修复方案**：更新测试脚本，使用正确的 API 路径：

## 六、性能优化建议

基于测试过程中发现的问题，提出以下优化建议：

### 6.1 添加数据库预加载（Eager Loading）

当前实现中，查询商家详情时会执行多次数据库查询（N+1 问题）。建议使用 SQLAlchemy 的 `selectinload` 或 `joinedload` 进行预加载：

```python
from sqlalchemy.orm import selectinload

stmt = select(Shop).options(
    selectinload(Shop.categories).selectinload(Category.products)
).where(Shop.id == shop_id)
```

### 6.2 添加 API 响应缓存

对于不经常变动的数据（如商家分类列表），建议添加缓存机制减少数据库压力：

```python
from fastapi_cache import FastAPICache
from fastapi_cache.decorator import cache

@router.get("/categories")
@cache(expire=300)  # 缓存5分钟
async def list_all_categories():
    ...
```

### 6.3 完善 API 文档

建议为所有 API 添加完整的 OpenAPI 文档注释，包括请求参数说明、响应示例和错误码定义。
